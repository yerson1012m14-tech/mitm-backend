# XITFORGE – pantalla de Key

La entrada de la app ahora empieza con una pantalla de Key visualmente separada del explorador.

Flujo de prueba:
1. Abrir XITFORGE.
2. Ver la pantalla `ACCESO SEGURO`.
3. Copiar una Key o usar `PEGAR KEY`.
4. Si el portapapeles ya tiene una cadena de 16 caracteres, la app la detecta al aparecer.
5. Pulsar `VERIFICAR Y ENTRAR`.
6. La pantalla de prueba acepta el formato y entra al explorador.

La validación remota multiusuario todavía debe sustituir el bloque marcado como `Punto de integración para la validación multiusuario del servidor`.
