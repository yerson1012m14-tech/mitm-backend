# JASON XIT v2.0

JASON XIT is an iOS-style File Manager and App Data container explorer with built-in access engine diagnostics, license key validation, and file manipulation capabilities.

## Features

- **Key Activation System**: 30-day licensing system with instant validation, live remaining countdown ticker, and renewal.
- **Access Engine (Motor)**: Live kernel status simulation, `kexploit_opa334` primitives, sandbox escape diagnostics, and output logs.
- **Filesystem Browser (Archivos)**: Browse `/var/mobile` device storage, inspect and edit `.plist`, `.json`, `.xml`, and text configuration files.
- **App Container Manager (AppData)**: Inspect sandboxed application containers (`Documents`, `Library/Preferences`, `tmp`) for installed apps (Safari, WhatsApp, Instagram, Discord, Spotify, etc.).
- **Cyber / Neon Theme**: Crimson glow visual identity with floating ember particle physics and iOS-native tab navigation.
